# Introducción

**ÁTICA FP** es una aplicación web para gestionar la formación del alumnado de Formación Profesional
en las empresas, a través de tres módulos: **FCT** (Formación en centros de trabajo), **FP dual**
(Formación profesional dual) y **FFEOE** (Formación en empresa).

Este manual está en elaboración. Su estructura prevista se describe en
[`docs/manual/README.md`](https://github.com/iesoretania/atica-fp/blob/v7/docs/manual/README.md).
